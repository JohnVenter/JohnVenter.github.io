Agentic Projects rclone sync

This is a personal configuration of rclone for synchronizing a filtered subset of the owner's local Agentic Projects folder with the owner's Google Drive. It is intended for the owner's use, not offered as a public service. The sync is not yet commissioned.

How it uses Google Drive

The Google OAuth authorization requests full Drive access because rclone needs to read and write files that may have been created outside rclone. When commissioned, the rclone remote will be configured to operate within one designated folder, but the OAuth permission itself is broader than that folder. Synced files may also be stored on the owner's Windows computer and personal OneDrive.

This website is informational only. It does not sign users in, request Google authorization, or receive Drive files or OAuth tokens.
