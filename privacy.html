Privacy policy

Agentic Projects rclone sync is a personal rclone configuration operated by the owner of the Google account that authorizes it. It is not a public service. This policy describes the intended use when synchronization is commissioned.

Google data accessed

Rclone requests full Google Drive permission. That permission can technically read, create, change, and delete Drive files. The configured remote will target one designated Agentic Projects folder, but Google does not limit the OAuth token to that folder.

Use, storage, and sharing

Drive file contents and metadata are used only to synchronize the owner's selected project files. Copies may be stored on the owner's Windows computer and in the owner's personal Microsoft OneDrive. OAuth credentials, sync state, and operational logs are stored on the owner's computer outside the synchronized project tree. This configuration does not sell user data or share it with other people. Google, Microsoft, and GitHub process data under their own service policies.

The static GitHub Pages site does not request Google authorization and does not receive Drive files or OAuth tokens. No analytics or tracking scripts are added to these pages by the app owner.

Control and retention

The account owner can stop synchronization and revoke the app's Google access in Google Account settings. Revoking access stops future API access; it does not automatically erase copies already stored locally or in OneDrive. Those copies must be managed separately. Operational files remain on the owner's computer until the owner removes them.

Questions

Contact the app owner using the support email displayed on Google's OAuth consent screen.
